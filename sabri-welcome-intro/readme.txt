Accessible, non-blocking welcome intro for the Sabri Social Homeopathy Platform.

== Description ==

File 13 provides the canonical welcome-intro experience only; File 20 remains the application-shell owner and File 25 remains the global visual-token owner. Version 1.1.0 implements the reconciled core plus the approved Future Welcome Experience Superset:

* first eligible visit with a minimum 30-day recurrence period, same-session and multi-tab suppression;
* logged-in account state plus privacy-minimal guest first-party cookie/localStorage fallback and reconciliation;
* home-only safe default with explicit suppression for login/account/recovery, clinical, booking, emergency, checkout and task routes;
* Continue, Skip, Close, Escape and Never Show Again controls;
* signed Replay Welcome plus version-aware replay for a materially new experience;
* no forced historical eight-second timeout by default; optional nonzero timing remains separately approval-gated and safety-bounded;
* adaptive full/light/static variants, Data Saver/slow-connection handling and a performance circuit breaker;
* reduced-motion, keyboard, focus restoration, screen-reader, RTL, safe-area, zoom and accessibility-profile support;
* localized governed copy resolver and Advanced Preview Lab states/variants/profiles;
* hidden-by-default fail-open behavior when JavaScript, CSS or storage fails;
* exact Sabri Green #087A4E local primary-token fallback with contextual orange accent;
* Founder visual-baseline approval state and deterministic visual-baseline hashing;
* authenticated cross-device preference synchronization and bounded rollback snapshots;
* optional aggregate-only analytics without IP address, user agent or fingerprint identifiers;
* approval-aware health/status evidence with explicit repository/staging/live truth boundary;
* File 20 registry/render contracts, File 24 safe-mode integration and File 25 token consumption;
* PWA/offline precache adapter without registering or owning a service worker;
* WordPress privacy exporter/eraser support and non-destructive uninstall.

== Installation ==

1. Upload the canonical release ZIP to a Hostinger-equivalent staging environment first.
2. Activate/upgrade the plugin and verify schema/config migration.
3. Open Settings > Sabri Welcome Intro and inspect health, Preview Lab and configuration.
4. Verify real File 00 / 20 / 24 / 25 integration, cache, browsers/devices and accessibility.
5. Complete Founder visual/copy acceptance, backup/restore and rollback rehearsal before production deployment.

A green repository workflow or ZIP build is not by itself staging, live or operational acceptance.
