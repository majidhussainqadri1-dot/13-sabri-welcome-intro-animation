# File 13 Governance Notice — 1.1.0

This repository implements **File 13 — Welcome Intro Animation** only. Its canonical boundary is an accessible, non-blocking welcome experience plus privacy-minimal recurrence/preferences, bounded configuration/diagnostics and approved Future Welcome adapters.

Governing hierarchy for this candidate:

1. latest explicit Founder-approved decision;
2. current consolidated central governing plan and later approved amendments;
3. current reconciled File 13 plan;
4. canonical cross-file contracts (File 00 identity, File 20 shell, File 24 assurance, File 25 visual system);
5. exact current repository source/evidence.

Repository code, PR state, CI, ZIP and staging/live deployment are separate realities. An old CI run or package cannot prove the current head. A green current-head workflow can prove only the repository gates it actually tests; staging/live/operational acceptance remains independent.

Founder visual approval is not ordinary WordPress administration: File 13 fails closed unless canonical Founder identity is explicitly asserted by File 00/an approved institutional adapter. File 13 never infers Founder status from `manage_options`, role slug, display name, email or numeric user ID.

Companion integrations are restriction-only. File 20/24 may impose stricter recurrence/routes/schedule/safe mode/privacy, but cannot lift a local denial or replace File 13-owned copy/preferences. File 25 remains the design-system owner.
