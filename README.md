## Purpose

The plugin provides an accessible eight-second public welcome sequence featuring:

- the Sabri Homeopathy SH logo;
- the American English brand name “Sabri Homeopathy”;
- the claim “The Tridimensional Healing System of Soul, Vital Force, and Matter”;
- a bright orange line animated from left to right;
- once-per-browser-session display through a session cookie;
- **Skip Intro** and **Escape** controls;
- a shortened static presentation for visitors who prefer reduced motion;
- fallback rendering for themes that do not call `wp_body_open()`.
