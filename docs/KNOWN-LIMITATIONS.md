# Known Limitations and Evidence Boundaries

These are not concealed source omissions; they are environment/approval gates that cannot be proven by repository code alone:

- active Hostinger WordPress/theme/LiteSpeed behavior;
- exact deployed File 00/20/24/25 provider versions and runtime signals;
- browser/OS/assistive-technology visual and accessibility differences;
- real network/cache/service-worker interactions;
- database/files backup restoration and live rollback timing;
- Founder visual/copy approval;
- production monitoring, support and incident response.

The module contains safe fallbacks and kill switches, but must remain a draft/unmerged deployment candidate until `STAGING-ACCEPTANCE.md` is signed.
